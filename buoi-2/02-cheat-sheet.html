Claude Code, một trang

In A4 · giữ bên máy

Bốn bước, ba lệnh, năm prompt. Đủ để làm lại một app khác mà không cần mở slide.

1Bốn bước, lặp lại

  1. Giao việcMột việc. Một file. Một tiêu chí đúng.
  2. Xem diffĐúng file, đúng chỗ, không có gì lạ.
  3. Chạy thửMở app, bấm như người dùng.
  4. CommitĐúng thì lưu mốc. Sai thì lùi.

2Ba lệnh terminal

# tải thư viện, chạy một lần
npm install

# chạy app ở localhost:3000
npm run dev

# xem file nào vừa đổi
git status

3Khi app hỏng

Claude sửa lanHoàn tác. Chia việc nhỏ hơn. Nói rõ file nào được sửa.
App không chạyQuay lại commit gần nhất. Đọc lỗi trong terminal.
Nó báo “đã xong”Mở app, bấm đúng luồng. Chưa thấy thì chưa xong.
Làm mãi không raDừng. Mô tả lại: mở đâu, bấm gì, thấy gì, mong đợi gì.

4Ba không

  • Không dán dữ liệu khách thật.
  • Không đưa mật khẩu, API key vào chat.
  • Không bấm Yes khi chưa đọc diff hoặc lệnh.
Commit trước mỗi việc. Không có mốc thì không có hoàn tác.

5Năm prompt dùng lại

Đổi một câuĐổi tiêu đề trang chủ thành “CRM hôm nay”. Chỉ sửa app/page.tsx.
Danh sáchĐọc data/khach-hang.csv. Tạo trang /khach-hang hiển thị bảng: tên, công ty, trạng thái, ngày gọi cuối.
Tìm và lọcThêm ô tìm theo tên. Thêm lọc theo trạng thái. Giữ nguyên các cột.
FormThêm form sửa khách: trạng thái, ngày gọi cuối, ghi chú. Bấm Lưu thì quay về danh sách.
Báo lỗiMở /khach-hang. Bấm lọc “Đang chăm”. Vẫn thấy khách “Chờ gọi”. Mong đợi: chỉ còn “Đang chăm”.
Trước khi bấm Yes Nó sửa file nào? Có gì ngoài phạm vi? Chạy lại được không?
