Bạn thấy thay đổi trước khi đồng ý.

Cùng một Claude, nhưng Code có tay.

Một dự án là một thư mục

crm-app/ ├─ app/ # các trang ├─ data/ # file CSV └─ package.json # thư viện

Mở đúng thư mục

Claude chỉ thấy những gì bên trong.

Mở sai chỗ thì nó không thấy dự án.

Trong buổi học: thư mục crm-app.

Cài một lần, dùng cả buổi

  1. Tải app Claude

    Bản desktop.

  2. Đăng nhập

    Tài khoản Cốc Cốc cấp.

  3. Mở tab Code

    Không phải tab Chat.

  4. Chọn thư mục

    Trỏ vào crm-app.

Không thấy tab Code? Nhắn trợ giảng trước buổi. Đừng đợi đến lớp.

Ba lệnh terminal đủ dùng

# tải thư viện, chạy một lần npm install # chạy app ở localhost:3000 npm run dev # xem file nào vừa đổi git status

Dán vào terminal. Không cần hiểu từng chữ.

Bốn bước, lặp cả buổi

  1. Giao việc

    Một việc. Một file. Một tiêu chí đúng.

  2. Xem diff

    Nó đổi gì?

  3. Chạy thử

    Mở app, bấm thử.

  4. Commit

    Đúng thì lưu mốc.

Bước 2 sai thì đừng sang bước 3.

Trước buổi, có đủ 5 thứ

  • App Claude đã đăng nhập, mở được tab Code.
  • Repo crm-app đã nằm trên máy.
  • npm run dev mở được localhost:3000.
  • GitHub và Vercel đã đăng nhập.
  • Biết ba lệnh ở slide trước.

Ba không: dữ liệu khách thật · mật khẩu trong chat · bấm Yes khi chưa đọc.
