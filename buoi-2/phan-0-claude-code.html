Chat trả lời. Code làm.

Cùng một app Claude. Tab Chat trả lời trong khung chat. Tab Code mở thư mục, đọc file, sửa file và chạy lệnh.

Một app, hai tab

Tab Chat

Dán nội dung vào, nhận câu trả lời bằng chữ.

Không đụng file trên máy.

Viết, phân tích, hỏi đáp.

Tab Code

Mở đúng thư mục dự án.

Đọc, sửa nhiều file. Chạy lệnh, chạy test.

Dựng và sửa một sản phẩm chạy được.

Code không thông minh hơn Chat. Nó có tay, nên có trách nhiệm.

Một dự án là một thư mục

crm-app/ ├─ app/ # màn hình ├─ components/ # khối dùng lại ├─ lib/ # hàm dùng chung ├─ data/ # dữ liệu mẫu └─ package.json # thư viện

Claude Code chỉ thấy thư mục bạn mở.

Muốn sửa đúng chỗ, mở đúng thư mục dự án.

Càng ít file, càng dễ đọc diff.
1

Cài trong 5 phút.

Tải app Claude, đăng nhập, mở tab Code. Không phải cài Node cho Claude Code.

Bốn bước cài đặt

  1. Cài Node 22 — nhờ IT nếu chưa quen.
  2. Tải app Claude ở claude.com/download.
  3. Đăng nhập, mở tab Code, chọn thư mục dự án.
  4. Thử “tóm tắt repo này”.

Cần tài khoản Claude trả phí. Bản free không có tab Code.

Ba lệnh terminal đủ dùng

LệnhĐể làm gì
cd crm-appVào thư mục dự án.
npm run devChạy app ở localhost:3000.
Ctrl + CDừng app.

Terminal chỉ là cửa sổ gõ lệnh. Gõ sai thì báo lỗi, không hỏng máy.

2

Bốn bước, lặp lại đến khi xong.

Giao việc → đọc diff → chạy thử → chốt. Vòng càng dài, càng khó biết hỏng ở đâu.

Một vòng làm việc ngắn

  1. Giao việc

    Một việc, một kết quả mong muốn. Nói rõ file và cách kiểm.

  2. Đọc diff

    File nào đổi, dòng nào thêm bớt. Chưa hiểu thì hỏi.

  3. Chạy thử

    Bấm đúng luồng vừa sửa. Lỗi thì dán nguyên văn.

  4. Chốt

    Chạy được thì commit. Không thì hoàn tác.

Một việc, một vòng. Đừng giao mười việc một lúc.

Giao việc cho Code khác giao cho Chat

Giao sơ sài

Làm form thêm lead.

Claude tự chọn file, tự chọn trường, tự đoán cách kiểm.

Giao đủ ý

Việc: thêm form tạo lead ở trang Lead. File: app/leads/new/page.tsx. Ràng buộc: không đổi cấu trúc dữ liệu, không thêm thư viện. Xong khi: tạo được lead, thiếu trường thì báo đúng trường.

Điều gì lặp lại mỗi vòng thì ghi vào CLAUDE.md hoặc AGENTS.md ở gốc dự án.

3

Diff là bản ghi những gì đã đổi.

Dòng thêm màu xanh, dòng bỏ màu đỏ. Đọc diff là kỹ năng chính của buổi này.

Một diff đọc trong 20 giây

--- a/lib/scoring.ts
+++ b/lib/scoring.ts
@@ -12,6 +12,9 @@
12export function scoreLead(l: Lead) {
13 return l.budget > 50 ? 80 : 40
13 let score = 40
14 if (l.budget > 50) score += 30
15 if (l.source === 'referral') score += 20
16 if (l.segment === 'enterprise') score += 10
17 return Math.min(score, 100)
18}

Không cần hiểu code. Cần thấy: một file, một hàm, năm dòng thêm, một dòng bỏ.

Đọc dòng đỏ trước.

Đáng ngờSửa file không ai nhờ. Xoá code đang chạy. Thêm thư viện lạ. Đọc dữ liệu nhạy cảm.

Ba câu hỏi khi đọc diff

Nó sửa file nào?

Ngoài file mình nhờ thì phải hỏi tại sao.

Dòng nào đổi?

Đọc dòng đỏ trước. Dòng xanh có đúng việc mình giao không?

Có gì lạ?

Thư viện mới, lệnh lạ, đụng dữ liệu nhạy cảm.

Không hiểu diff thì đừng bấm đồng ý. Hỏi: “giải thích đoạn này”.

4

Quyền là phanh, không phải giấy phép.

Claude Code hỏi trước khi sửa file hoặc chạy lệnh. Mỗi lần đồng ý là một lần bạn nhận trách nhiệm.

Đồng ý cái gì, từ chối cái gì

ViệcMức quyềnBạn làm gì
Đọc file trong dự ántự độngKhông cần duyệt.
Sửa filehỏiĐọc diff trước.
Chạy lệnh terminalhỏiĐọc lệnh. Lạ thì từ chối.
Xóa file, thư mụchỏiĐọc kỹ đường dẫn.
Cài thư viện mớihỏiBiết để làm gì mới đồng ý.
Đọc dữ liệu nhạy cảm, gửi dữ liệu ra ngoàichặnThêm vào danh sách chặn.

Tự đồng ý sửa file chỉ bật khi đã commit. Không bật ở buổi học.

5

Không commit thì không có mốc để quay về.

Git là nút Ctrl+Z của cả dự án. Commit trước mỗi vòng.

Bốn lệnh git đủ dùng

LệnhĐể làm gì
git statusCó gì đã đổi, chưa chốt.
git diffTừng dòng thêm bớt.
git add -A rồi git commit -m "..."Chốt một mốc để quay về.
git checkout -- .Bỏ mọi thay đổi chưa commit.

Commit nhỏ, ghi rõ đã làm gì. Không đưa mật khẩu hay khóa truy cập vào dự án.

Nó hiếm khi nói “không làm được”. Nó sửa thêm file, hoặc bảo xong khi chưa chạy thử.

7

Máy bạn là môi trường thật.

Code chạy lệnh bằng quyền của bạn. Dữ liệu thật, mật khẩu, khóa truy cập đều trong tầm với.

Năm điều không làm

  1. Không dùng dữ liệu thật. Chỉ dùng bộ dữ liệu mẫu.
  2. Không đưa mật khẩu, khóa truy cập lên mạng. Không dán vào chat.
  3. Không chạy lệnh dán từ ngoài. Nhất là lệnh tải và chạy mã lạ.
  4. Không duyệt lệnh mà chưa đọc. Lệnh xoá, push, cài: đọc rồi bấm.
  5. Không tin mọi thứ Claude đọc vào. File, web, email đều có thể chứa lệnh ẩn.

Bản demo chỉ cần dữ liệu hư cấu.

8

Đến lớp với máy đã sẵn sàng.

Thực hành chiếm hơn nửa buổi. Sửa máy tại lớp thì cả nhóm phải chờ.

Checklist trước buổi

  • App Claude đã đăng nhập, mở được tab Code
  • Repo mẫu đã tải về máy
  • App mẫu mở được ở localhost
  • Tài khoản GitHub và Vercel đã đăng nhập
  • Máy đã cài Node 22 và Git

Thiếu mục nào thì báo trước buổi.
